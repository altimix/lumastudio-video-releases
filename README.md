# LumaStudio VIDEO 公式配布

Windows / macOS向けの動画編集アプリです。個人・学校・団体・企業で無償利用できます。商用目的でも利用できます。

**最新版は v1.10.13 です。** [ダウンロードと更新情報](https://github.com/altimix/lumastudio-video-releases/releases/tag/v1.10.13)から、お使いの環境に合うアプリを入手してください。

| お使いの環境 | ダウンロード | 起動方法 |
| --- | --- | --- |
| Windows 64bit | [Luma-Studio-1.10.13-Windows.exe](https://github.com/altimix/lumastudio-video-releases/releases/download/v1.10.13/Luma-Studio-1.10.13-Windows.exe) | [Windows向け案内](https://github.com/altimix/lumastudio-video-releases/releases/download/v1.10.13/README-Windows.txt) |
| Mac（Apple Silicon） | [Luma-Studio-1.10.13-macOS-arm64.zip](https://github.com/altimix/lumastudio-video-releases/releases/download/v1.10.13/Luma-Studio-1.10.13-macOS-arm64.zip) | [Mac向け案内](https://github.com/altimix/lumastudio-video-releases/releases/download/v1.10.13/README-Mac.txt) |

Windows版は64bitのポータブルEXE、Mac版はApple Silicon用のZIPです。[SHA256SUMS.txt](https://github.com/altimix/lumastudio-video-releases/releases/download/v1.10.13/SHA256SUMS.txt)で配布ファイルのチェックサムを確認できます。
