# LumaStudio VIDEO 公式配布

Windows / macOS向けの動画編集アプリです。個人・学校・団体・企業で無償利用できます。

**最新版は v1.10.12 です。** [ダウンロードと更新情報](https://github.com/altimix/lumastudio-video-releases/releases/tag/v1.10.12)から、お使いの環境に合うアプリを入手してください。

- [VIDEO公式サイト・使い方](https://lumastudio.altimix.jp/video/)
- [LumaStudioシリーズ（VIDEO・PDF・CAD）](https://lumastudio.altimix.jp/)
- [画像付きマニュアル](https://lumastudio.altimix.jp/manual/)
- [アプリの利用条件](LICENSE)
- [不具合・機能の提案](https://github.com/altimix/lumastudio-video-releases/issues)
- [お問い合わせ](https://altimix.co.jp/contact/)

Windows版は64bitのポータブルEXE、Mac版はApple Silicon用のZIPです。起動方法はリリースに添付した `README-Windows.txt` / `README-Mac.txt` を確認してください。`SHA256SUMS.txt` で配布ファイルのチェックサムを確認できます。
